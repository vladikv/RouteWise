# Decisions

Why RouteWise is built the way it is. The plan (`docs/PLAN.md`) says *what* is built; this file says *why*.

## What goes in here

Record a decision when it affects the architecture, an API contract, data or the schema, security, a
dependency or external service, or the development process, or when it changes an earlier entry. UI styling
and layout details belong in the commit message or `frontend/CLAUDE.md`, not here.

Add new entries at the end of the log with the next number. Never edit or delete an old entry: when a
decision changes, add a new one and set the old entry's status to "Superseded by #N".

## Key decisions

The decisions that shape the project, as they stand now. Details and reasons are in the log entries.

| Area | Decision | Entries |
|---|---|---|
| Architecture | Layered Spring Boot API (`controller → service → repository`), package by feature; business rules are pure functions; layering enforced by ArchUnit | #129 |
| Data | H2 in memory with the schema owned by Flyway migrations (never `ddl-auto`); zero-setup run, schema still versioned | #1 |
| Data | Comparisons are computed, not stored; the backend owns all trip figures, filters, facets and KPIs, the UI only displays them | #2, #122 |
| Domain | Scoring: route distance = haversine × detour factor per mode; time, cost and CO₂ min-max normalised among available modes and weighted by the trip priority; weather multiplies the score | #15, #16, #18 |
| Domain | Multi-stop trips: `Trip` owns 2–10 ordered stops; the comparison is per leg, with a mixed itinerary compared against single-mode totals | #77, #78 |
| Domain | Ground modes only within one landmass (fixed links count, ferries do not); flights use DEFRA short- and long-haul CO₂ factors | #110, #115 |
| Resilience | Weather is best effort: cached (successes only, 1 h), one retry, explicit `weatherStatus`; the comparison never fails because of it | #19, #130, #131 |
| AI | The LLM is optional (bean only with `ANTHROPIC_API_KEY`) behind `AdvisorClient`; rule-based parser and writer are the fallback on absence or any failure | #22, #23 |
| AI | LLM output is never trusted: drafts are validated like user input and the recommended mode always comes from the engine | #24 |
| Security | Session login (HttpOnly `JSESSIONID`), not JWT; CSRF cookie pattern with `CsrfCookieFilter`; another user's trip answers 404 | #53, #57, #55 |
| API | Errors are RFC 7807 Problem Details from one global handler, including Spring MVC's own errors | #6 |
| API | Soft delete with an explicit `deleted_at`; restore within a window (200, idempotent) or 409 after it; Undo in the UI | #126, #127 |
| Frontend | Angular with CLI defaults (standalone, zoneless, signals); no UI library, own design tokens; dark theme only | #28, #29, #143 |
| Frontend | Interactive SVG globe with `d3-geo` only; the map and charts are never the only way to get information | #109, #43 |
