# RouteWise UI

Angular single-page app for RouteWise. See the root `README.md` for the project
and `CLAUDE.md` in this folder for structure and conventions.

```bash
npm install
npm start        # http://localhost:4200 (expects the API on http://localhost:8087)
npm test         # unit tests (Vitest), single run
npm run lint     # ESLint (angular-eslint)
npm run build    # production build into dist/
```
